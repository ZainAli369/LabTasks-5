# Basic Know How of all tasks

**Task 1:** Checks student eligibility and merit. Invalid data and boundary cases are also tested.

**Task 2:** Uses a grading table, sorting, and `reduce()` for department statistics.

**Task 3:** Updates student objects while preserving nested data and explains object references.

**Task 4:** Demonstrates `this`, `call()`, and `bind()`.

**Task 5:** Uses separate modules, imports, and error handling.

**Task 6:** Demonstrates callbacks and callback nesting.

**Task 7:** Uses `Promise.allSettled()` and `Promise.any()` to handle multiple promises and server requests.

**Task 8:** Handles HTTP, network, JSON, and timeout errors. `Promise.all()` fetches dashboard data concurrently.
